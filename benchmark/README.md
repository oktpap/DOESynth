# Бенчмарк: выбор модели и дооптимизации по умолчанию

Все числа получены сдаваемым путём: фаза → 8-битный ДОЭ → фаза из кода → Френель → |K|² →
8 бит (максимум → 255) → SSIM условия и Пирсон против исходных изображений. Полные таблицы —
[`summary.md`](summary.md), сырые данные — `results*.json`, время — `timing.json` (CPU в
контейнере, после прогрева).

## Наборы

- **Наборы отчёта** (`sets.npz`, 228 комплектов, `make_sets.py`):
  - validation — 4 комплекта: фото, документы, буквы, смешанные (scikit-image);
  - незнакомые категории — 24 комплекта, которых генератор обучения не рисует: алфавиты,
    пиктограммы, графики, формулы, фракталы, оптические моды;
  - сечения 3D-объектов — 200 комплектов: 4 сечения одного объекта, отложенное разбиение.

  Средние берутся по каждому набору, затем по трём наборам с равным весом.
- **Выборка настройки** (`tune.npz`, 264 комплекта, `make_tune.py`) — для подбора
  дооптимизации, с наборами отчёта не пересекается: 200 сечений из разбиения validation и
  64 четвёрки генератора обучения (сид 777).

## Порядок

1. **Первый проход** (`benchmark.py`, правило в docstring записано до запуска).
   17 сетей, дооптимизация одним критерием. Пирсон при lr 0,4 лучше всех остальных вариантов,
   но SSIM у всех низкий (≈ 0,44) — ниже контроля «в каждой плоскости среднее целей»
   (0,43 по SSIM).
2. **Причина.** SSIM условия сравнивает средние яркости, а восстановление нормируется на
   максимум. Яркие пики спекла делают изображение тёмным: среднее после нормировки в 2–4 раза
   ниже, чем у цели. Оптимизация по одному Пирсону этого не видит. Прямой SSIM в loss
   оптимизируется плохо: градиент максимума получает один пиксель.
3. **Настройка на выборке настройки** (`ssim_tuning.py`, `ssim_tuning*.json`).
   Градиент максимума пропускается через p-норму (p = 8, значение остаётся точным максимумом).
   Схема двухэтапная: половина шагов — Пирсон (lr 0,4), половина — Пирсон + SSIM
   (lr 0,05). При тех же 100 шагах SSIM растёт с 0,386 до 0,498, Пирсон падает на 0,018.
   Вариант выбран из 31 (два раунда: доля этапов, lr, p): на обеих проверенных сетях он
   лучший или в пределах 0,001 от лучшего.
4. **Второй проход** (`benchmark.py --v2`) со схемой из п. 3 — на выборке настройки
   (`results_tune_v2.json`) и на наборах отчёта (`results_v2.json`). Шаги и модель выбираются
   на выборке настройки по правилу из п. 1, числа отчёта берутся с наборов отчёта.
   - Число шагов: наименьшее N, при котором SSIM лучшей сети не ниже SSIM при 300 шагах минус
     0,01. Получилось **200**.
   - Модель: максимум SSIM при N, при разнице < 0,002 — больший Пирсон. Получилась
     **3D-CGH-Net (R08-paper)**: 0,5096 против 0,5089 у следующей (R08-skip). Отрыв —
     в пределах шума; первые пять сетей — варианты 3D-CGH-Net.
   - На наборах отчёта по тому же правилу выбор совпадает: 200 шагов и R08-paper.

Выводы:

- Двухэтапная дооптимизация — главный источник качества по SSIM: +0,13 к дооптимизации
  одним Пирсоном при том же Пирсоне.
- Старт из сети лучше старта из суперпозиции при равном числе шагов: +0,006 SSIM
  при 200 шагах и +0,009 при 100 (парные разности, на наборах сечений и validation значимы).
  Качество Adam-1000 (4,7 с) сеть с дооптимизацией набирает за 300 шагов (1,5 с) —
  втрое быстрее.
- После дооптимизации все 17 сетей отличаются меньше чем на 0,008 SSIM. Без дооптимизации
  лучшая сеть — 3D-CGH-Net с 8 обучаемыми шагами спуска (SSIM 0,355 за 0,1 с). Она в 12 раз
  быстрее GS-500 и лучше его по обеим метрикам.
- Без дооптимизации все сети по SSIM ниже контроля «среднее целей» (0,428). По Пирсону лучшая
  из них (gd8, 0,554) выше контроля (0,539). Основной вклад в качество по умолчанию даёт
  дооптимизация, сеть — хороший старт для неё.
- Если важнее время, 100 шагов дают SSIM 0,559 за 0,55 с
  (`finetune_steps` в `doesynth/catalog.py`).
- Формула условия с одним БПФ заворачивает свет, вышедший за окно 1,28 мм, на другую сторону
  поля. Метрики считаются по формуле условия. Переносить их на реальный ПВМС без оговорки
  нельзя: по проверке методом углового спектра в окно попадает ≈ 65 % энергии.

## Оговорка: |K| или |K|²

Условие не уточняет, что считать восстановленным изображением. Решение считает
интенсивность |K|², и под неё обучены все сети. Если эксперты возьмут модуль |K|, на validation
и незнакомых категориях (28 комплектов, сеть + 200 шагов) будет так:

| Дооптимизация | Оценка по \|K\|²: SSIM / Пирсон | Оценка по \|K\|: SSIM / Пирсон |
| --- | --- | --- |
| Двухэтапная (по умолчанию) | 0,559 / 0,632 | 0,418 / 0,592 |
| Только Пирсон | 0,465 / 0,645 | 0,396 / 0,611 |

По SSIM двухэтапная схема лучше при любой конвенции, по Пирсону уступает 0,013–0,019.

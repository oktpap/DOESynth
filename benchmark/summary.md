# Сводка бенчмарка

SSIM и Пирсон — средние по трём наборам (каждый набор — среднее по четвёркам), по сдаваемому пути: 8-битный ДОЭ → Френель → |K|² → 8 бит (максимум → 255).
Время — CPU в контейнере (CPU, 6 потоков), после прогрева.

Выбор сделан на: выборка настройки (volume_validation, generator); таблицы ниже — по наборам отчёта.
Шагов дооптимизации по умолчанию: **200** (наименьшее N, где SSIM лучшей сети ≥ SSIM при 300 шагах − 0.01). Модель по умолчанию: **cghnet_paper_r08** (максимум SSIM, при разнице < 0.002 — больший Пирсон). Лучшая сеть без дооптимизации: **cghnet_gd8_r08**.

SSIM лучшей сети на выборке выбора в зависимости от числа шагов дооптимизации:

| шаги | 20 | 50 | 100 | 200 | 300 |
|---|---|---|---|---|---|
| SSIM | 0.429 | 0.475 | 0.498 | 0.510 | 0.514 |

Пять лучших сетей на выборке выбора (SSIM / Пирсон при выбранном N): cghnet_paper_r08 0.5096 / 0.6047; cghnet_skip_r08 0.5089 / 0.6043; cghnet_planes_r08 0.5080 / 0.6036; cghnet_pass2_r08 0.5072 / 0.6022; cghnet_skip_clean_r08 0.5068 / 0.6014.

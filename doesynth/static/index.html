DOESynth
Синтез фазового ДОЭ для четырёх плоскостей Френеля
—

Исходные изображения

Порядок файлов по имени = порядок плоскостей. Можно перетащить файл на ячейку.

Метод синтеза

Нейросеть

Итерационный метод

Ctrl+Enter
Загрузите четыре изображения
По одному на плоскость восстановления: z = 24,1 / 25,3 / 26,5 / 27,7 мм.
Или выберите комплект в меню «Примеры».
Пакетная обработка комплектов

Выберите папку, в которой каждая подпапка — комплект из 4 изображений, или ZIP-архив с такими папками. Порядок плоскостей — по имени файла. Используются метод и параметры из левой панели.
